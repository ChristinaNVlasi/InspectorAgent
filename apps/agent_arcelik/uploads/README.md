# Uploads Folder

Place your test files here for inspection:

## Audio Files (Noise Diagnosis)
Supported formats:
- `.wav` - WAV audio
- `.mp3` - MP3 audio
- `.m4a` - M4A audio
- `.ogg` - OGG audio
- `.webm` - WebM audio

Example:
```
water_pump_noise.m4a
bearing_worn_out.wav
motor_issue.mp3
```

## Image Files (Damage Detection)
Supported formats:
- `.jpg` / `.jpeg` - JPEG images
- `.png` - PNG images

Example:
```
cabinet_panel_damaged.jpg
detergent_dispenser.png
front_wall_scratched.jpg
```

## Usage

Once files are in this folder, you can reference them by just the filename:

```
Analyze water_pump_noise.m4a
Check cabinet_panel_damaged.jpg
Diagnose bearing_worn_out.wav
```

The system will automatically find the files in this uploads folder!
